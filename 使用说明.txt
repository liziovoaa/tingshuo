上海中考英语听说模拟器 · 使用说明
=====================================

一、怎么打开

  【在线版·推荐给学生】
    网址：https://liziovoaa.github.io/tingshuo/
    或在微信里扫「二维码-在线版.png」。
    手机、平板、电脑都能开，不用装东西。第一次会问「使用麦克风」，要点允许。
    建议用手机 Chrome / Edge / 微信内置浏览器；iPhone 用 Safari 也能录，
    但如果录不出声，换成手机上的 Chrome。

  【离线版·自己备课用】
    双击「上海中考英语听说模拟器.html」即可，无需安装、无需联网。
    推荐浏览器：Edge 或 Chrome（要能录音）。Mac 上请用 Edge，Safari 录音兼容性差。
    第一次打开会弹出「使用麦克风」的授权，点允许。

二、文件说明（这些必须放在同一个文件夹）
  上海中考英语听说模拟器.html   主程序
  题库数据.js                   12 套题库（自动生成，别手改）
  音频/                         72 段题目录音（应答 5×12 + 复述 12），必须一起带
  素材图片/                     第 3、7、11、12 套的看图表达图片
  素材/、素材文本/              原始 docx/doc 与解析出的文本（可留可删）

  * 音频是随包自带的，不依赖系统朗读、也不联网。少一个文件夹就听不到题。

三、考试流程（与真实机考一致）
  1. 首页选一套 → 3 秒后自动开始
  2. Ⅰ 朗读：词组（准备 10 秒 / 朗读 15 秒）→ 句子（准备 10 秒 / 朗读 10 秒）
  3. Ⅱ 交际应答：5 题，每题先听问题（屏幕上没有题干），准备 10 秒、应答 10 秒
  4. Ⅲ 复述：短文播两遍 → 准备 50 秒 → 复述 50 秒
  5. Ⅳ 表达：看题（或看图）→ 准备 50 秒 → 表达 50 秒，至少 5 句
  * 提示音「叮」= 开始录音，低音「咚」= 录音结束；每题结束自动进入下一题
  * 想提前结束本题：点右下角「跳过本题」

四、考完能看什么
  · 诊断分（10 分制，四项各 2.5）
  · 每项扣分点清单：语速、停顿次数、有效发声时长、语调起伏、句数
  · 自己的录音回听（▶ 回听）+ 波形图 + 音高曲线
  · 参考答案：朗读语调、交际应答可接受说法、复述听力原文、表达参考范文
  · 复述/表达的「要点自查」勾选框：勾了会实时改分

五、关于评分（重要）
  官方是机器评分 + 人工抽检，机评引擎不对外，任何网页工具都复刻不了。
  这里的分数只统计「能测到的部分」：
      语音语调  ← 音高曲线起伏、句末升降
      流利度    ← 语速、停顿次数、最长停顿
      内容量    ← 有效发声时长、句数
      内容要点  ← 孩子自己听录音勾选（工具不替孩子猜）
  所以把它当「体检报告」用，别当预测分。要看真实水平，还得老师听录音。

六、题库来源与版权
  题库来自教辅《中考模拟听说测试》12 套（docx + mp3），已转成结构化题目。
  自己教学、给自己学生练没问题；如果要公开对外分发，题目需换成原创，
  界面里也不要用「官方」「上海市教育考试院」这类字样。

七、想加新题
  1. 把新的 docx 放进 素材/（文件名带「测试十三」这样的序号）
  2. 跑一次：python tools/build_bank.py
  3. 会自动更新 题库数据.js 和 data/bank.json，刷新网页即可看到
  4. 还要给新题配音：python tools/build_audio.py
     （只补新的即可，已有的会自动跳过；装依赖：pip install edge-tts）
  5. 表达题若是表格/思维导图，先跑 python tools/extract_visual.py

八、怎么更新线上版
  改完题库或主程序后，跑一次：
      python tools/发布到GitHub.py
  它会自动重建发布目录、提交、推送、等线上生效（约 1 分钟），
  不用手动进 GitHub 网页操作。改了主程序文件记得连「题库数据.js」一起在。

九、已知限制
  · 评分不含语法、发音是否准确（需要语音识别，离线做不到，也不该瞎猜）
  · 录音对比是「句级」，做不到「哪个词念错」的词级对齐
  · 题目朗读是预生成录音（Edge 神经语音，标准美音），不是原书配套的原声
  · 报告页的「▶ 听范文 / 听参考答案」走系统语音，国内 Chrome 的英文语音
    是 Google 在线音色、连不上服务器就没声；这类按钮听不到时不必在意，
    题目本身的声音全部来自内置录音，不受影响
  · 在线版是公开链接，谁拿到都能看。只发给自己的学生，别往公开群里转
